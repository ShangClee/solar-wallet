# Solar Wallet Codebase Overview

This is the **Solar Wallet** codebase, a multi-platform Stellar wallet application developed by SatoshiPay. It allows users to manage Stellar accounts, assets, payments, and trading.

### 1. Project Overview

- **Type**: Cryptocurrency Wallet for the Stellar Network.
- **Platforms**: Desktop (Electron for macOS, Windows, Linux), Mobile (Cordova for iOS, Android), and Web.
- **Core Features**: Account management, multi-signature support, asset management (trustlines), payments, and a decentralized exchange (DEX) interface.
- **Security**: Local key storage with `PBKDF2` + `xsalsa20-poly1305` encryption.

### 2. Tech Stack

- **Language**: **TypeScript** (primary), Java (Android hooks), Shell scripts.
- **Frontend Framework**: **React** (Hooks & Context API).
- **UI Library**: **Material-UI (v4)** with custom styling.
- **Build Tool**: **Parcel** (for bundling), **Electron Builder** (for desktop packaging).
- **Stellar SDK**: `stellar-sdk` for blockchain interaction.
- **State Management**: React Contexts (no Redux/MobX seen; uses `src/App/contexts/`).
- **Testing/Dev**: Storybook for component development (`.storybook/`).

### 3. Key Directory Structure

The codebase is organized to share maximum code between platforms:

- **`src/`**: The core application logic (Shared React Code).
  - **`App/`**: Application bootstrapping, global contexts (`contexts/`), and routing.
  - **`Account/`, `AccountCreation/`**: Account management and setup flows.
  - **`Assets/`**: Managing Stellar assets and balances.
  - **`Payment/`, `Transaction/`**: Logic for sending/receiving payments.
  - **`Trading/`**: Interface for the Stellar DEX (Decentralized Exchange).
  - **`Platform/`**: Abstraction layer handling platform-specific logic (e.g., how `clipboard` or `notifications` work on Web vs. Electron vs. Cordova).
  - **`Workers/`**: Web Workers for offloading heavy tasks (network/crypto) from the main thread.
- **`electron/`**: Electron-specific main process code (`src/app.ts`, `src/menu.ts`).
- **`cordova/`**: Configuration and hooks for mobile builds (Android/iOS).
- **`shared/`**: Types and utilities shared between the frontend and platform-specific code.

### 4. Development Workflow

Common commands found in `package.json`:

- **Install Dependencies**: `npm install`
- **Run Desktop Dev**: `npm run dev` (Runs Electron + Parcel watcher)
- **Run Web Dev**: `cd web/ && npm run dev`
- **Run Storybook**: `npm run storybook` (UI Component playground)
- **Build Production**: `npm run build:mac`, `npm run build:win`, etc.

### 5. Notable Architecture Details

- **Platform Abstraction**: The app uses a `Platform` module (`src/Platform/`) to inject platform-specific implementations (like file storage or deep linking) into the shared React app.
- **Optimistic UI**: The `Workers/net-worker/optimistic-updates` directory suggests the app updates the UI immediately before the blockchain transaction confirms, for a snappier user experience.
